# Benchmark Examples

This directory contains reusable public benchmark launchers grouped by benchmark family.

## Available Examples

- [dabench](dabench/README.md): full DABench launcher aligned with the main README flow
- [sciencebench](sciencebench/README.md): full ScienceBench launcher plus extra dependency notes
- [moscibench](moscibench/README.md): MoSciBench launcher for the released `competitions/` layout
- [dacode](dacode/README.md): DACode launcher for prepared `dacode-*` task trees

Each subdirectory contains a small Python script, a shell launcher, and benchmark-specific notes.
